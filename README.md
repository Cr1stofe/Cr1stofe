## 💡 Featured Projects

### 🎓 [LMS — NestJS Backend API](https://github.com/Cr1stofe/lms-nest-postgres)

Scalable enterprise REST API built with NestJS and PostgreSQL. Features modular architecture, granular RBAC access control, secure `__Secure-sid` cookie authentication with Argon2id hashing, streaming protection via Caddy's `X-Accel-Redirect` (HTTP 206 Partial Content), Vitest automated testing, and multi-stage Docker deployment.

- **Techs:** `NestJS`, `PostgreSQL`, `Prisma ORM`, `Docker`, `Caddy`, `Vitest`, `Argon2`

### 💻 [LMS — Next.js Frontend](https://github.com/Cr1stofe/lms-front-next)

Modern educational platform frontend built with Next.js App Router and BFF architecture. Features zero-lag HTML5 video streaming with HTTP Range Requests, atomic state management with Zustand, real-time schema validation with Zod + React Hook Form, and responsive Dark Luxury UI with SCSS Modules.

- **Live Demo:** [veltro.cr1stofe.dev](https://veltro.cr1stofe.dev/)
- **Techs:** `Next.js`, `React 19`, `TypeScript`, `Zustand`, `React Hook Form`, `Zod`, `SCSS Modules`

### ⚡ [Personal Portfolio](https://github.com/Cr1stofe/portfolio)

Modern personal portfolio engineered with Next.js 16 (Turbopack), React 19, TypeScript, i18n (PT-BR / EN-US), Vitest, automated CI/CD pipeline, and SEO/A11y optimizations.

- **Live Demo:** [cr1stofe.dev](https://cr1stofe.dev)
